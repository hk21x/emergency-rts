Emergency Ops

Every element from the style sheet, rebuilt as a clean vector. Pick one and take it as SVG or a PNG at 1x, 2x or 4x — nothing is baked into a sprite sheet. Blank frames are the ones you ship; anything labelled is a spacing spec. A matching Godot 4 project ships in the same download.

Icons are drawn on a 24×24 grid with fill="currentColor" — inline them and set color to recolour. Brand marks in 01-brand are fully outlined and need no font; everything else is set in Rajdhani and Barlow.
